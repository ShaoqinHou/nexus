# Research solo-dev user-intent traceability workflow

User wants the workflow expanded for solo-dev interaction patterns: initial app/background prompt, later vague ideas, feature requests, bug follow-ups, and clarifications. The workflow should capture compact user-intent slices rather than whole prompts, transform them into lead-understood feature/work slices when appropriate, preserve source/traceability, avoid unmanaged one-off docs, support generated on-the-run documentation for LLM and human use, and remain lightweight enough for solo development. Research should compare existing practices and decide whether this belongs as policy only, a subsystem inside the current kernel, a larger redesign, or a replacement architecture.
